## 막힌 것 / 해결
- `push -u origin main`만 쳐서 `command not found` → git 명령은 `git`으로 시작해야 한다는 걸 알게 됨
- 앱 폴더가 두 개(`dev-journal/myday`, `Documents/myday`)가 돼서 어디서 작업해야 할지 헷갈림 → 하나로 합침
- `dev-journal` 저장소를 지우고 당황함 → GitHub은 90일간 복구 가능하고,
  애초에 로컬 `.git`에 역사가 다 있어서 잃은 게 없었음
- 저장소를 연습용/제출용 계정으로 나눠야 하나 고민 → 계정이 아니라 repo를 목적별로 나누는 게 맞다는 결론
